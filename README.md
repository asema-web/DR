# Memory Calendar

    npm install
    npm run dev      # разработка
    npm run build    # сборка в dist/

Фото месяцев: положи файлы `01.jpg` … `12.jpg` в `public/months/`
(July и November уже есть). Любое фото месяца можно также сменить
прямо на сайте, на странице месяца.

Данные: люди и заметки в localStorage, фотографии в IndexedDB (браузер этого устройства).
